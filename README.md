# Cognitive Terrain · Playtest downloads

**Play and download: https://kw-wargame.github.io/cognitive-terrain-releases-playtest/**

![A turn of play: Blue previews a move on Olvana's News Media and strikes, then Olvana answers.](images/play.gif)

An educational, turn-based wargame of cognitive warfare: Blue vs Red (Olvana or Donovia). It runs in your browser; the game is supported in the browser only for now.

Immersive Briefings is an optional setting: a free voice pack; press ▶ LISTEN in the week in review to hear the week read aloud. It never starts by itself, and the game is complete without it. Load it from Settings › Immersive Briefings. The pack contains open-source components under their own licences (see its release page); `.github/voice-pack` is the script that builds it.
