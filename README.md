Immersive Briefings is an optional setting: a free voice pack that reads each week in review aloud. The game is complete without it. Load it from Settings › Immersive Briefings, or put it beside an installed game (Windows, Mac, Linux). The pack contains open-source components under their own licences (see its release page); `.github/voice-pack` is the script that builds it.
